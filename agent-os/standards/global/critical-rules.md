# Critical Rules

This is a working product with real users. It evolves gradually.

1. **Never break existing functionality.**
2. **Never remove working features.**
3. **Don't rewrite backend logic** unless the task genuinely requires it.
4. **Don't change API shapes** unless required — the mobile app and TWA consume the same endpoints and ship separately.
5. Default focus is UI, UX, and bug fixing.

## Product bar

Target the polish of MyFitnessPal, Strong, Apple Fitness, Nike Training Club. Decisions should look like a consumer app used by millions — not a generic AI-generated layout.

## When making a large UI change

1. Analyze the current layout
2. Identify the actual UX problem
3. Propose the improvement
4. Then implement

Deliberate and structured. Not random restyling.
