# Agent Instructions

**The project instructions live in [`CLAUDE.md`](./CLAUDE.md). Read that file.**

It covers the repository layout, the domains, backend and frontend architecture, the
data-compaction policy, the voice-first product design, the UI design system, and the
available MCP tools and agent tooling. Everything there applies regardless of which
assistant or CLI you are running.

This file used to be a find-and-replace copy of `CLAUDE.md`, which meant the two drifted
apart and it ended up describing directories that do not exist. It is deliberately a
pointer now so that cannot happen again.
